# Session 01 — 2026-05-24

**Theme:** POC inception — prove each pipeline capability individually, then run the first end-to-end render on a real video.

---

## What was done

1. Aligned on the original creator request from "C" (8-item wishlist: highlight trim, zoom, overlays, Thai subs, SFX, HeyGen, n8n, multi-AI).
2. Scoped a 1-day POC focused on the core editing pipeline. Out-of-scope: SFX, HeyGen, Drive integration, n8n, UI.
3. Built `CLAUDE.md` and `POC_PLAN.md` documenting tech decisions and the in/out-of-scope split.
4. Validated capabilities one-by-one:
   - **Whisper local CPU** — faster-whisper large-v3 int8 works on CPU; ~10 min per minute of audio; ~3-4 GB RAM. Operator confirmed "10 min wait is fine for an influencer queue."
   - **`claude -p` subprocess** — works with `--output-format json`; bills against Pro plan Agent SDK credit; no API key needed.
   - **FFmpeg + libass for Thai** — `drawtext` produces empty boxes for Thai (FreeType only); `.ass` via libass renders correctly.
   - **python-ass** — clean API for `.ass` generation; supports our Style/Dialogue pattern.
5. First end-to-end run on `20260401_084849.mp4` (1:30 video) produced a 580MB output mp4 with subs + drawtext popups. Visible Thai glyphs confirmed.
6. Second test extracted a 23.6s highlight reel proving cut → concat → overlay path.

---

## Decisions made (foundation table)

| Decision | Choice |
|---|---|
| Transcription | faster-whisper large-v3 (CPU, int8 quantized) |
| LLM | `claude -p` subprocess on Pro plan Agent SDK credit (no API key) |
| Video processing | FFmpeg via subprocess (not ffmpeg-python — banned, unmaintained) |
| Subtitle format | `.ass` + libass via FFmpeg `subtitles` filter |
| Subtitle font | Noto Sans Thai (Sarabun not in apt) |
| Architecture | Modular pipeline: transcribe → highlight → edit → subtitle |
| Audit | Save intermediate JSON + final mp4 with timestamps |
