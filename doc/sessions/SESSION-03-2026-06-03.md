# Session 03 — 2026-06-03

**Theme:** Thai word wrapping with PyThaiNLP; pause-based resegmentation; Claude cleanup pass introduction.

---

## What was done

1. Researched Thai subtitle word-break industry standards. Confirmed:
   - libass's `wrap_unicode` (libunibreak) breaks Thai anywhere — semantically wrong for subtitles
   - PyThaiNLP `newmm` is the de facto standard tokenizer
   - Best practice: tokenize → insert `\N` line breaks at word boundaries
2. Built `clipforge/textwrap_th.py` with `wrap_thai(text, max_chars_per_line, max_lines)` — PyThaiNLP newmm + greedy pack + `\N` insertion.
3. Tested with strict per-line enforcement: 67-char Thai sentence → 3 lines of 11-12 chars each, no overflow, clean word boundaries.
4. Wired into `subtitle.py::make_overlay_ass` for both Speech and KeywordPop styles.
5. **Added pause-based resegmentation** in `transcribe.py::_resegment_at_pauses` — splits long Whisper segments at word-level pauses (>= 0.4s gap OR >= 1.0s single-token-held-through-silence).
6. Discovered: 88-char Whisper segment with 5s span (1 pause inside) split nicely into 2 sub-segments. But sometimes the split lands inside a PyThaiNLP word boundary (e.g. `แถม` → `แ` + `ถม`) — known cosmetic debt, deferred.
7. **Style match iterations:**
   - Measured target subtitle row count (1-3 lines, NEVER 4+) and width (median 68%, max 87% of frame)
   - Our v5 was 4-6 rows and 26-62% width — way too narrow + too tall
   - Tuned `char_width_ratio` (0.7 → 0.32) and `margin_horizontal` (200 → 50) and font-size formula (`height/19` → `height/14`)
   - v6: 1-4 rows, 45% median width. v8/v11: 1-3 rows, 60%+ width — getting close
8. **Critical bug fix: `Sara Am` decomposition** — Whisper sometimes outputs `ทํา` (decomposed) instead of `ทำ` (precomposed). Added deterministic normalisation as Step 1 of cleanup pass.
9. **Introduced Claude cleanup pass** — proofread Whisper output with rules + memory + topic context:
   - `clipforge/cleanup.py` module
   - `clipforge/cleanup_rules.md` — static guidelines (4-5K chars curated, with Thai fitness vocabulary)
   - `clipforge/cleanup_memory.md` — empty placeholder; grows with operator-confirmed corrections
   - Confidence-gated correction application (default threshold: medium)
10. **First cleanup pass test on real content:** found 5 high-confidence corrections in v10:
    - `ยอด → ย่อ` (×2): "peak" → "lower down" (movement cue)
    - `บ่ายเจ็บ → ปวดเจ็บ`: "afternoon pain" → "aches and pains"
    - `ฟังชันอล → ฟังก์ชันนัล`: "functional" loanword
    - `เสือ → เสื่อ`: "tiger" → "mat" (context-disambiguated by fitness rules)
11. Subtitle style iterations:
    - White + thick black outline (v10-11) → not matching target
    - **Client provided `target-font-screenshot.jpg`** showing white + drop-shadow, no outline, large bold
    - Switched to drop-shadow style (`outline_width: 0`, `shadow: 10`, semi-transparent black back_color)
12. Font iteration: Noto Sans Thai (default looped) → Sarabun (client: "buckles, old school") → Prompt (loopless but tone marks colliding). Diagnostic: `fonttools` GPOS lookup count: Prompt 5, Sarabun 8.

---

## Decisions made

| Decision | Choice |
|---|---|
| Thai word tokenization | PyThaiNLP `newmm` (dict-based, fast, no ML) |
| Line wrapping | Insert `\N` at word boundaries; do not rely on libass auto-wrap |
| Pause-based resegmentation | Active in `overlay_only` only; uses Whisper word timestamps |
| Cleanup pass | Rules+memory pattern with confidence gating |
| Subtitle style | White + drop shadow (no outline) — matches target font screenshot |
